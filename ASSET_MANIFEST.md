## Removed from the active scene

The earlier forest-wanderer character and separate sword prop are not loaded by the current scene. Their runtime URLs and staging logic have been removed; they are not active scene assets.

## Environment

Terrain, hills, trees, instanced grass, flower patches, broad-leaf ground cover, stones, lighting, and staging are generated by project code in `index.html` and `grass-system.js`.

## Runtime dependencies

- Three.js `0.183.0` and `GLTFLoader` are imported from jsDelivr at runtime.
- The warrior GLB is loaded from the Cinevva asset CDN.
- This is not an offline/self-contained build. Network availability and CDN CORS policy are runtime requirements.
- Asset failures are logged to the browser console; a persistent error overlay is not currently provided.
